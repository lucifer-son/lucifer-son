### ✈️ Sistemas Distribuídos para Aviónica

[**Acessar
repositório**](https://github.com/lucifer-son/Sistemas_Distribuidos_Avionica)

software · tolerância a falhas

### 🛫 Controle Aeroportuário com Concorrência

[**Acessar
repositório**](https://github.com/PP-DC-UFRPE/projeto-da-2a-va-controleaeroportuario-paradigmas)

Aplicação acadêmica em Java para simular operações de controle
aeroportuário. O projeto trabalha com threads, gerenciamento de pistas,
estados de aeronaves e coordenação de operações concorrentes, destacando
a importância da sincronização e do tratamento de condições de corrida.

**Temas:** Java · concorrência · threads · sincronização · programação
orientada a objetos

### 📈 Análise de Desempenho e Teoria das Filas

Projeto acadêmico de avaliação de desempenho de uma aplicação web
utilizando Apache JMeter, execução de experimentos com diferentes níveis
de carga e análise de métricas como latência, vazão e variabilidade. Os
resultados foram relacionados a conceitos de teoria das filas para
investigar capacidade, ponto de saturação e degradação sob concorrência
elevada.

**Temas:** Apache JMeter · testes de carga · métricas de desempenho ·
teoria das filas · análise de dados

### 🧪 Modelagem e Simulação de Sistemas Computacionais

Atividades acadêmicas e de pesquisa voltadas à modelagem e simulação de
sistemas, incluindo o estudo de redes de Petri, métricas de desempenho e
simulação de sistemas distribuídos e de aviónica.

**Temas:** modelagem · simulação · redes de Petri · OMNeT++ · sistemas
críticos

### 🖼️ Processamento de Imagens

Projeto acadêmico utilizando Python e OpenCV para estudar técnicas de
processamento de imagens, incluindo filtragem, operações morfológicas,
localização de regiões de interesse e reconhecimento de caracteres em
placas.

**Temas:** Python · OpenCV · processamento de imagens · filtros · OCR
